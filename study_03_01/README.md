# 🐧 리눅스마스터 2급 CBT & 합격 마스터 (문제집 올인원 v2.0)

국가공인 **리눅스마스터 2급(1차 및 2차 시험)** 합격을 위한 실전 CBT 퀴즈 및 핵심 요약 정리 통합 웹 애플리케이션입니다.  
공인 문제집의 **486개 기출 전 문항**과 **11개 챕터 핵심 이론**을 전수 추출하고, 리눅스 표준 man-pages 및 공인 시험 기준에 따라 **철저한 교차검증(Cross-Verification)**을 거쳐 제작되었습니다.

외부 라이브러리나 복잡한 빌드 과정 없이 **HTML5, CSS3, Vanilla JavaScript (Zero-Dependency)**로 제작되어 높은 안정성과 즉각적인 실행을 지원합니다.

### 🌟 [방법 1] 단일 파일(Single File)로 카톡/에어드랍 전송 후 열기 (가장 추천 ⭐⭐⭐)

1. `study_03_01` 폴더의 **`linux_master_offline.html`** 파일(약 390KB)을 스마트폰으로 전송합니다:

   - **아이폰 (iOS)**: 에어드랍(AirDrop)으로 전송

4. *(꿀팁)* 브라우저 메뉴에서 **[홈 화면에 추가]**를 누르면, 앱스토어에서 받은 정식 앱처럼 아이콘이 생성되어 전체화면으로 실행됩니다.

### 🌐 [방법 2] GitHub Pages로 평생 무료 모바일 웹사이트 만들기 (한 번 설정으로 끝 ⭐⭐)
PC를 아예 켜지 않고도 전 세계 어디서든 스마트폰 주소창으로 접속할 수 있는 가장 편리한 클라우드 방식입니다:

1. 작업한 코드를 GitHub 저장소에 푸시(`git push`)합니다.  
   *(※ 문제집 원본 PDF 파일은 `.gitignore`에 의해 자동으로 제외되므로 저작권 걱정 없이 안심하고 푸시할 수 있습니다.)*
2. 본인 GitHub 저장소 페이지의 **[Settings] ➔ [Pages]** 탭으로 이동합니다.
3. **Branch**를 `main`으로 선택하고 **[Save]** 버튼을 누릅니다.
4. 약 1~2분 후 다음과 같은 **전용 모바일 웹 주소**가 생성됩니다:
   ```text
   https://<본인-깃허브-아이디>.github.io/Practical_AI/study_03_01/index.html
   ```
5. 스마트폰 브라우저에 해당 주소를 즐겨찾기(북마크)해 두면 평생 무료로 언제 어디서든 접속할 수 있습니다!

## ✨ 핵심 기능 및 시스템 구성

### 1. 1차 & 2차 완전 분리 퀴즈 시스템
- **상단 퀵 스위처**: `[전체]` / `[1차 대비 (88제)]` / `[2차 대비 (398제)]`를 클릭 한 번으로 전환.
- **1차 시험 전용**: 리눅스의 이해(역사, 오픈소스 철학, 라이선스, 배포판), 리눅스 설치 및 설정(파티션, swap, LILO/GRUB), 기본 명령어(파일/디렉터리 조작, 권한, 사용자 관리).
- **2차 시험 전용**: 리눅스 운영 및 관리(파일시스템, 쉘, 프로세스, 에디터 vi, 패키지관리 rpm/yum/apt, 장치설정) + 리눅스 활용(X윈도우, 네트워크/인터넷 프로토콜, 신기술 클러스터/가상화/임베디드).

### 2. 합격 대비 7대 전문 퀴즈 및 연습 모드
1. **💡 학습형 연습 모드 (신규 추가 ⭐⭐⭐)**: 문제를 풀자마자 정답 여부(초록/빨강)와 명령어 속성 상세 해설이 즉시 펼쳐지는 추천 학습 모드! 문제를 풀기 전 **[💡 정답 & 해설 바로보기]** 기능도 지원하여 부담 없이 문항별 원리를 학습할 수 있습니다.
2. **📋 실전 CBT 모의고사**: 1차 20문항 / 2차 40문항 출제, 60점 합격선 판정 및 **40점 미만 과목별 과락 진단표** 실시간 출력.
3. **⚡ 서바이벌 데스매치**: 단 한 문제만 틀려도 즉시 게임 오버! 최대 연속 정답 기록(Streak) 훈련.
4. **⏱️ 10초 타임어택**: 문제당 10초 카운트다운 타이머 구동, 실전 순발력 강화.
5. **🎯 과목/챕터별 집중 공략**: 취약한 특정 챕터(예: 네트워크, vi 에디터, umask 권한 등)만 골라 100% 마스터.
6. **🛡️ AI 교차검증 킬러문항 챌린지**: 수험생 오답률 1위인 umask 권한 계산, SetUID/Sticky Bit, 시그널 번호, 서브넷팅 계산 문제 집중 출제.
7. **🔄 스마트 오답노트 집중 재시험**: 틀린 문제만 로컬 스토리지에 자동 수집하여 정답을 맞출 때까지 반복 재시험.

### 3. 📖 핵심 요약 정리관 (Study Hub)

- 실시간 키워드 검색, 아코디언 펼침, 복사 및 가독성 최적화.

## 🛡️ AI 정답 교차검증 (Cross-Verification) 내역

모든 기출문제와 보기는 다음 표준을 기반으로 **전수 교차검증**되었습니다:
- **POSIX.1-2017 & Linux Man-Pages**: 시그널 번호(1: SIGHUP, 2: SIGINT, 9: SIGKILL, 15: SIGTERM), 프로세스 우선순위(-20~19), chmod 특수 권한 비트(SetUID: 4000, SetGID: 2000, Sticky: 1000).
- **FHS 3.0 디렉터리 표준**: `/etc`, `/proc`, `/var`, `/usr/local` 용도 검증.
- **IANA 표준 네트워크 포트**: FTP(20: 데이터, 21: 제어), SSH(22), Telnet(23), SMTP(25), DNS(53), HTTP(80), HTTPS(443).
- **한국정보통신진흥협회(KAIT) 공식 기출 정답표**: 시험 과목별 배점, 과락 판정 기준 대조.

상세 검증 내역은 [`VERIFICATION_REPORT.md`](file:///C:/Users/Jinsung/git/Practical_AI/study_03_01/VERIFICATION_REPORT.md) 문서에서 확인하실 수 있습니다.
