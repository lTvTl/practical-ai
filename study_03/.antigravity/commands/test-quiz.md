# 🧪 퀴즈 데이터 및 로직 무결성 검증 (`/test-quiz`)

이 명령어는 `questions.js` 데이터베이스의 문항 정합성을 검증하고, 스크립트 실행 또는 정적 분석을 통해 잠재적 오류를 사전 탐지합니다.

## 🔍 검증 체크리스트

1. **문항 필수 필드 검사**:
   - 모든 객체가 `id`, `subject`, `question`, `options`, `answer_index`, `explanation` 필드를 온전히 가지고 있는지 확인
2. **ID 고유성 검사**:
   - 중복된 `id` 번호가 없는지 검사
3. **보기(options) 유효성**:
   - `options` 배열의 길이가 정확히 4개인지 확인
   - 빈 문자열 보기(`""`)가 없는지 확인
4. **정답 인덱스 범위**:
   - `answer_index`가 `0`, `1`, `2`, `3` 중 하나인지 확인
5. **과목 균형도 점검**:
   - 5개 표준 과목(`소프트웨어 설계`, `소프트웨어 개발`, `데이터베이스 구축`, `프로그래밍 언어 활용`, `정보시스템 구축관리`)에 속해 있는지 확인
   - 과목별 문제 수 통계 집계 및 편중 여부 점검
6. **코드 구문 오류 검사**:
   - `questions.js` 및 `app.js`에 문법 에러나 미참조 변수가 없는지 Node.js 또는 정적 파서로 확인

프로젝트 루트에서 다음 명령어로 즉시 문항 무결성 및 통계를 검증할 수 있습니다:

