# 📊 퀴즈 범위 분석 커스텀 명령어 (`/quiz-range $시작번호 $끝번호`)

이 명령어는 `questions.js` 데이터베이스에서 지정한 번호 범위(`$시작번호` ~ `$끝번호`)의 문제들을 선별하여 **데이터 무결성 검증**, **과목별 분포**, **정답 번호 균형도(1~4번)**, **지문/해설 텍스트 통계**를 종합적으로 분석합니다.

---

## 📌 사용법 (Usage)

```text
/quiz-range $시작번호 $끝번호
```

### 호출 예시
- `/quiz-range 1 20`: 1번부터 20번까지 문항 집중 분석
- `/quiz-range 21 40`: 21번부터 40번까지 문항 집중 분석
- `/quiz-range 1 60`: 전체 문항 종합 심층 통계 분석

---

## 🔍 분석 항목

1. **추출 문항 수 및 비율**:
   - 전체 문항 대비 해당 구간의 비중(%) 확인
2. **데이터 무결성 검증**:
   - 범위 내 모든 문항의 필수 필드, 보기 4개, 정답 인덱스 범위(0~3), 해설 누락 여부 검사
3. **과목별 문항 분포**:
   - 해당 범위에 포함된 과목 통계 및 백분율 집계
4. **정답 번호 분포 (1~4번 편중도 분석)**:
   - 정답 번호가 1, 2, 3, 4번에 골고루 분포되어 있는지 막대그래프로 시각화
5. **텍스트 통계**:
   - 평균 지문 글자 수 및 평균 해설 글자 수 측정
6. **문항 요약 리스트**:
   - 문제 ID, 과목, 정답 번호, 지문 요약 목록 제공

## 💻 빠른 CLI 실행

터미널에서 직접 실행할 수 있습니다:

```bash
# 예: 1번부터 20번 문항 분석
node .antigravity/commands/analyze-range.js 1 20

# 예: 25번부터 36번 문항 분석
node .antigravity/commands/analyze-range.js 25 36
```

---

## 🤖 에이전트 실행 지침

1. 사용자가 입력한 `$시작번호`와 `$끝번호` 파라미터를 확인합니다.
   - 인자가 부족할 경우(예: 시작번호만 입력 등), 사용자에게 범위를 입력해 줄 것을 요청합니다.
   - 시작번호가 끝번호보다 큰 경우 바로잡도록 안내합니다.
2. 터미널 명령 `node .antigravity/commands/analyze-range.js $시작번호 $끝번호`를 실행합니다.
3. 분석 결과를 다음 표와 마크다운 서식으로 정리하여 사용자에게 가독성 있게 브리핑합니다:
   - **범위 개요 및 무결성 상태**
   - **과목별 문항 수**
   - **정답 번호 분포 및 쏠림 여부**
   - **핵심 통계 (지문/해설 길이)**
   - **문항 리스트 요약**
