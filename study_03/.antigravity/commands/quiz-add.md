# ➕ 퀴즈 문제 추가 커스텀 명령어 (`/quiz-add $카테고리 $난이도`)

이 명령어는 사용자가 지정한 **카테고리(과목)**와 **난이도**에 맞추어 새로운 정보처리기사 필기 문제를 `questions.js`에 표준 규격대로 안전하게 추가하고, 즉시 유효성을 검증합니다.

---

## 📌 사용법 (Usage)

```text
/quiz-add $카테고리 $난이도 [문제내용(선택)]
```

### 호출 예시
- `/quiz-add "소프트웨어 설계" "상"`: 소프트웨어 설계 과목 고난도(심화/응용) 신규 문제 생성 및 추가
- `/quiz-add "데이터베이스 구축" "중"`: 데이터베이스 구축 과목 중급(기출 빈출) 신규 문제 추가
- `/quiz-add 4과목 하`: 프로그래밍 언어 활용 기초/개념 문제 추가
- `/quiz-add "정보시스템 구축관리" "중" 지문: ... 보기: ... 정답: ... 해설: ...`: 사용자가 직접 준비한 문제를 검증하여 추가

---

## 🎯 매개변수 기준 (Parameters)

### 1. `$카테고리` (5대 표준 과목)
입력된 카테고리는 다음 5대 표준 명칭 중 하나로 매핑됩니다:
1. `소프트웨어 설계` (1과목)
2. `소프트웨어 개발` (2과목)
3. `데이터베이스 구축` (3과목)
4. `프로그래밍 언어 활용` (4과목)
5. `정보시스템 구축관리` (5과목)

### 2. `$난이도` 기준
- **상 (고급 / High)**:
  - 복합 응용, 계산식, 복잡한 코드 트레이싱, 함정 보기 포함, 심화 아키텍처/알고리즘
- **중 (중급 / Medium)**:
  - 기출 빈출 유형, 핵심 원리 이해, 표준 SQL 및 다이어그램 분석
- **하 (초급 / Low)**:
  - 기본 용어 정의, 핵심 키워드 매칭, 기본 개념 이해

---

## 📋 표준 문제 데이터 규격 (Schema)

기존 `questions.js` 데이터베이스의 객체 스키마 형식을 100% 동일하게 준수합니다:

```javascript
{
  id: <고유 번호 (기존 마지막 id + 1)>,
  subject: "<5대 표준 과목명>",
  question: "<문제 지문>",
  options: [
    "<보기 1>",
    "<보기 2>",
    "<보기 3>",
    "<보기 4>"
  ],
  answer_index: <정답 인덱스 (0, 1, 2, 3 중 하나)>,
  explanation: "<핵심 개념 및 오답 분석을 포함한 친절한 상세 해설>"
}
```

---

## 🛡️ 동일 검증 가이드라인 (Validation Checklist)

신규 추가되는 모든 문제는 기존과 동일한 엄격한 검증 가이드라인을 통과해야 합니다:

1. **ID 고유성 및 자동 순번 채번**:
   - 기존 `questions.js`의 `MAX(id) + 1`을 배정하여 중복 및 누락 방지
2. **필수 필드 6종 완전성**:
   - `id`, `subject`, `question`, `options`, `answer_index`, `explanation` 모두 누락 없이 존재
3. **보기(options) 유효성**:
   - 보기는 **정확히 4개**의 문자열로 구성
   - 빈 문자열(`""`) 보기가 없어야 함
4. **정답 인덱스 범위**:
   - `answer_index`는 반드시 **`0`, `1`, `2`, `3`** 중 하나 (0-based)
5. **해설 충실도**:
   - 정답의 이유뿐만 아니라 다른 보기들에 대한 오답 분석을 포함한 충실한 해설 제공
6. **추가 후 자동 검증 필수**:
   - 코드에 삽입 후 반드시 `node .antigravity/commands/validate-questions.js <신규ID>`를 실행하여 무결성 통과 확인

## 🤖 에이전트 실행 워크플로우

1. **인자 분석**:
   - `$카테고리`를 5대 표준 과목명으로 정규화합니다.
   - `$난이도`가 상/중/하 중 어떤 수준인지 파악합니다.
2. **문제 구성**:
   - 사용자가 구체적인 문제 내용을 제공한 경우: 해당 내용을 규격에 맞게 포맷팅합니다.
   - 문제 내용이 제공되지 않은 경우: 해당 과목 및 난이도에 부합하는 실제 정보처리기사 필기 기출/예상 문제를 정밀하게 생성합니다.
3. **ID 채번 및 파일 반영**:
   - `questions.js`에서 현재 최대 `id`를 확인하고 `id = MAX(id) + 1`을 부여합니다.
   - `questions.js`의 해당 과목 영역에 문제를 추가합니다.
4. **자동 검증 실행**:
   - 터미널에서 `node .antigravity/commands/validate-questions.js <신규ID>`를 실행하여 문법 오류나 규격 위반이 없는지 검사합니다.
5. **결과 보고**:
   - 추가된 문제의 ID, 과목, 난이도, 지문 요약, 정답 및 검증 통과 결과를 사용자에게 보고합니다.
