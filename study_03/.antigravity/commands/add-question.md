# ➕ 기출문제 추가 커스텀 명령어 (`/add-question`)

이 명령어는 사용자가 제공한 신규 기출문제를 `study_03/questions.js`의 `QUESTION_BANK` 배열 규격에 맞추어 안전하게 검증하고 추가합니다.

## 📋 표준 문제 데이터 규격 (Schema)

모든 문제는 아래 객체 형식을 엄격히 준수해야 합니다:

```javascript
{
  id: <고유 번호 (기존 마지막 id + 1)>,
  subject: "<과목명 (아래 5개 과목 중 하나)>",
  question: "<문제 지문>",
  options: [
    "<보기 1>",
    "<보기 2>",
    "<보기 3>",
    "<보기 4>"
  ],
  answer_index: <정답 인덱스 (0, 1, 2, 3 중 하나)>,
  explanation: "<핵심 개념 및 오답 분석을 포함한 친절한 상세 해설>"
}
```

### 5대 과목 표준 명칭
1. `소프트웨어 설계`
2. `소프트웨어 개발`
3. `데이터베이스 구축`
4. `프로그래밍 언어 활용`
5. `정보시스템 구축관리`

---

## ⚙️ 실행 절차

1. **사용자 입력 확인**:
   - 추가할 문제 지문, 보기 4개, 정답 번호, 해설, 해당 과목을 확인합니다.
   - 정보가 누락된 경우 사용자에게 입력을 요청하거나 보완합니다.
2. **중복 검사 및 ID 배정**:
   - `questions.js` 파일을 조회하여 기존 문제들과 지문이 중복되는지 검사합니다.
   - 현재 등록된 가장 큰 `id` 값을 찾아 `신규 id = MAX(id) + 1`로 자동 설정합니다.
3. **과목별 섹션 배치**:
   - 해당 과목 주석 블록(예: `// 1과목: 소프트웨어 설계`) 하단에 적절히 배치하여 가독성을 유지합니다.
4. **유효성 검증**:
   - `options` 배열의 길이가 정확히 4개인지 확인합니다.
   - `answer_index`가 0 이상 3 이하의 정수인지 확인합니다.
   - 문법 오류(쉼표 누락, 따옴표 이스케이프 등)가 없는지 확인합니다.
5. **결과 보고**:
   - 추가된 문제의 ID, 과목, 문제 요약 및 전체 문항 수를 사용자에게 안내합니다.
