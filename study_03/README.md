# 정보처리기사 기출 퀴즈 게임 (CBT Quiz Challenge)

국가기술자격 **정보처리기사 필기 기출문제**를 게임처럼 몰입감 있게 풀며 실전 감각을 극대화하고 자격증 합격을 달성할 수 있는 반응형 웹 퀴즈 게임 애플리케이션입니다.  
외부 라이브러리나 복잡한 빌드 과정 없이 **순수 HTML5, CSS3, Vanilla JavaScript (Zero-Dependency)**로 제작되어 높은 안정성과 즉각적인 실행을 지원합니다.

실제 정보처리기사 수험생의 학습 니즈에 맞춘 **6가지 전문 모드**를 지원합니다:

| 모드 | 아이콘 | 특징 및 수험 대비 목적 |
| :--- | :---: | :--- |

| **서바이벌 데스매치** <br>*(하드코어)* | ⚡ | **단 한 번의 오답으로 즉시 탈락!**<br>실제 시험장에서의 실수를 방지하고 극도의 긴장감 속에서 최고 연속 정답 기록(Streak)을 세우는 훈련입니다. |

## 💎 역동적인 점수 시스템 (Dynamic Scoring System)

단순한 정답 개수를 넘어, 게임성과 실전 감각을 고조시키는 **3단계 복합 점수 시스템**을 도입했습니다:

1. **기본 배점 (Base Score)**:
   * 정답 1개당 **100 pt** 기본 획득
2. **연속 정답 콤보 (Streak Combo System)**:
   * 연속으로 정답을 맞출 때마다 콤보 카운트 누적 및 차등 보너스 부여
   * 2콤보: `+25 pt` | 3콤보: `+50 pt` | 4콤보: `+75 pt` | 5콤보 이상: `+100 pt` (문제당 최대 200pt)
   * 콤보가 쌓일수록 Web Audio 효과음의 피치(음높이)가 올라가며 화면에 불꽃 콤보 애니메이션 연출
   * 오답 시 콤보 리셋
3. **스피드 판단력 보너스 (Speed Bonus)**:
   * 문제 출제 후 정답 선택까지의 소요 시간에 따라 추가 보너스 지급
   * **3초 이내**: `+50 pt` (초광속 판단!)
   * **6초 이내**: `+30 pt` (신속 정답!)
   * **10초 이내**: `+15 pt` (안정적 정답!)
4. **성적 등급 (Tier System)**:
   * 최종 획득 점수와 모드 판격에 따라 **5단계 티어 배지** 수여
   * 👑 **S등급** (수석 합격권, 정답률 90% 이상)
   * 🥇 **A등급** (안정 합격권, 정답률 80% 이상)
   * 🥈 **B등급** (가상 합격권, 정답률 60% 이상)
   * ⚠️ **C등급** (과락 위험 / 보충 권장, 정답률 40% 이상)
   * 🚨 **F등급** (불합격권)

## 📋 실전 모의고사: 과목별 과락 진단표

실제 정보처리기사 필기시험은 **전 과목 평균 60점 이상이더라도, 단 한 과목이라도 40점 미만이면 과락으로 즉시 불합격** 처리됩니다.
* 시험 종료 시 5개 과목 각각의 정답 수와 백분율을 시각적 게이지 바로 제공합니다.
* 40% 미만 과목 발생 시 `[⚠️ 과락 불합격]` 경고와 함께 과락 과목명을 명시하여 수험생이 보완해야 할 취약점을 정확히 짚어줍니다.

## 📝 스마트 오답노트 관리 모달

* 게임 도중 틀린 모든 문제는 브라우저 `localStorage`에 자동 수집됩니다.
* 메인 화면의 **[📝 오답노트 확인]** 버튼을 통해 언제든지 보관된 문제의 지문, 정답, 상세 해설을 열람하고 개별 삭제하거나 전체 초기화할 수 있습니다.
* **[🚀 오답만 다시 풀기]** 버튼을 눌러 틀렸던 문제들만 집중적으로 다시 풀며 완전 학습을 달성할 수 있습니다.
