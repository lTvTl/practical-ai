# 📝 정보처리기사 기출 퀴즈 게임 PRD (제품 요구사항 정의서) v2.0

## 1. 프로젝트 개요
**정보처리기사 CBT 퀴즈 챌린지**는 수험생 및 예비 개발자들이 정보처리기사 자격증 필기 기출문제를 게임처럼 재미있고 몰입도 있게 풀며, 실제 시험에서 가장 중요한 **과목별 과락 방지**와 **실전 시간 배분 능력**, **오답 복습**을 체계적으로 훈련할 수 있도록 돕는 웹 퀴즈 애플리케이션입니다.

---

## 2. 게임 모드 시스템 (Game Modes)

실제 수험생의 학습 니즈에 맞추어 6가지 특화 모드를 제공합니다:

1. **실전 CBT 모의고사 (Mock Exam Mode):**
   * 5개 전 과목(소프트웨어 설계, 소프트웨어 개발, 데이터베이스 구축, 프로그래밍 언어 활용, 정보시스템 구축관리)에서 균등하게 2문제씩 총 10문제를 출제합니다.
   * 실제 정처기 필기 룰에 따라 **전 과목 평균 60점 이상 & 매 과목 40점 이상(과락 방지)** 판정을 적용합니다.
   * 시험 종료 후 5개 과목별 득점 게이지 및 과락(40% 미만) 여부를 시각적으로 진단합니다.

2. **서바이벌 데스매치 (Survival Mode):**
   * 단 한 문제도 틀려선 안 되는 1-Life 극한 챌린지입니다.
   * 오답을 선택하는 즉시 게임 오버 처리되며, 최대 연속 정답 수(Streak)를 기록합니다.

3. **10초 타임어택 (Time Attack Mode):**
   * 문제당 10초의 카운트다운 타이머가 작동합니다.
   * 10초 이내에 답을 고르지 못하면 자동 시간 초과 오답 처리됩니다.

4. **과목별 집중 공략 (Subject Mastery Mode):**
   * 5개 과목 중 학습자가 취약한 특정 과목을 선택하여 해당 과목의 10문제를 집중 학습합니다.

5. **스마트 오답노트 (Wrong Note Mode):**
   * 플레이 중 틀린 문제들이 로컬 스토리지에 자동 수집되며, 오답 문제만 선별하여 재시험을 치를 수 있습니다.
   * 오답 퀴즈에서 정답을 맞히면 오답노트에서 자동으로 제거됩니다.

6. **클래식 10제 (Classic Mode):**
   * 600문제 은행(5개 과목 각 120문제)에서 무작위 10문제를 추출하여 빠르게 푸는 표준 모드입니다.

## 3. 다이내믹 점수 및 콤보 시스템 (Scoring System)

동기부여와 성취감을 높이기 위해 복합 포인트 시스템을 적용합니다:

1. **기본 점수:** 정답 시 100 pt
2. **연속 콤보 보너스:**
   * 2콤보: +25 pt
   * 3콤보: +50 pt
   * 4콤보: +75 pt
   * 5콤보 이상: +100 pt
   * 오답 시 콤보 0으로 리셋
3. **스피드 판단력 보너스:**
   * 3초 이내 정답: +50 pt
   * 6초 이내 정답: +30 pt
   * 10초 이내 정답: +15 pt
4. **성적 티어 (Tiers):**
   * 👑 **S등급** (수석 합격권 / 90% 이상)
   * 🥇 **A등급** (안정 합격권 / 80% 이상)
   * 🥈 **B등급** (가상 합격권 / 60% 이상)
   * ⚠️ **C등급** (과락 위험 / 40% 이상)
   * 🚨 **F등급** (불합격권)

## 4. 인게임 및 학습 보조 기능

1. **즉각적 피드백 & 상세 해설:**
   * 정답/오답 즉시 시각 및 사운드 피드백 제공
   * 정답 선택 후 하단에 핵심 해설 박스가 펼쳐져 충분한 복습 시간 확보
2. **Web Audio API 프로시저럴 사운드:**
   * 콤보가 증가할수록 피치가 상승하는 딩동음
   * 타임어택 째깍 소리 및 타임아웃 경고음
   * 서바이벌 탈락 비장음 및 최종 합격 팡파레
3. **명예의 전당 (Leaderboard):**
   * 획득 포인트(pt), 맞힌 개수, 소요 시간을 기준으로 정렬
   * 모드별 필터(전체, 모의고사, 서바이벌, 클래식, 타임어택) 지원
4. **키보드 단축키 지원:**
   * 숫자 1, 2, 3, 4로 보기 선택
   * Space / Enter로 다음 문제 이동 및 결과 확인
   * ESC로 모달 닫기
