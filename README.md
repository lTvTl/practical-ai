## 1. [study_01] 손글씨 숫자 인식 프로그램 (Handwritten Digit Recognizer)

사용자가 캔버스 화면에 마우스로 숫자(0~9)를 직접 그리면, 머신러닝 모델이 실시간으로 어떤 숫자인지 인식하여 결과를 표시해주는 데스크톱 애플리케이션입니다.

### ✨ 주요 기능
- **직관적인 드로잉 캔버스**: 400x400 크기의 캔버스에 자유롭게 숫자 드로잉
- **머신러닝 기반 숫자 인식**: Scikit-learn의 `digits` 데이터셋으로 학습된 Random Forest 모델을 통해 실시간 예측
- **이미지 자동 전처리**: 사용자가 그린 고해상도 이미지를 모델 입력 규격(8x8 다운샘플링 및 정규화)으로 실시간 변환
- **캔버스 초기화(Clear)**: 원클릭으로 캔버스를 지우고 새로운 숫자 테스트 가능
- **독립 실행 파일(.exe) 패키징 지원**: PyInstaller를 통한 단일 실행 파일 빌드 구성 지원

### 🛠️ 기술 스택
- **언어**: Python 3.10+
- **머신러닝 & 연산**: `scikit-learn`, `numpy`, `scipy`
- **GUI & 이미지 처리**: `tkinter`, `Pillow`
- **테스트 & 배포**: `pytest`, `pyinstaller`

### 🚀 실행 방법
```bash
# 1) 디렉터리 이동
cd study_01

# 2) 필수 라이브러리 설치
pip install -r requirements.txt

# 3) 프로그램 실행
python main.py
```

### 🧪 테스트 실행
```bash
# 단위 테스트 실행 (모델 & GUI 변환)
pytest test_digit_recognition.py test_gui.py

# 종합 수동 워크플로 시뮬레이션 테스트
python test_manual_workflow.py
```

## 2. [study_02] 개인용 할 일 관리 애플리케이션 (Daily Task Tracker)

매일 10~20개의 할 일을 효율적으로 관리할 수 있도록 설계된 직관적이고 반응성이 뛰어난 단일 페이지 웹 애플리케이션(SPA)입니다.

### ✨ 주요 기능
- **⚡ 키워드 기반 스마트 자동 카테고리 분류**:
  - 할 일 입력 시 키워드(예: *회의, 운동, 공부* 등)를 실시간 분석하여 카테고리(`💼 업무`, `🌿 개인`, `📚 공부`) 자동 추천
  - 사용자 환경에 맞춘 자동 분류 On/Off 스위치 및 원클릭 카테고리 순환 변경 지원
- **🌓 다크 / 라이트 모드**: 원클릭 테마 전환 및 시스템 환경 자동 감지 (설정 영구 저장)
- **⭐ 중요도 별표(Priority)**: 중요 항목 지정 및 대시보드 통계 집계, 중요 항목 모아보기 필터
- **🔍 실시간 검색**: 입력과 동시에 일치하는 할 일을 1초 만에 필터링
- **🔀 드래그 앤 드롭(Drag & Drop)**: 마우스 드래그로 우선순위 순서 자유롭게 재배치
- **🎉 동기부여 효과**: 100% 목표 달성 시 Canvas Confetti 폭죽 효과 및 연속 달성 스트릭(🔥 N일 연속) 카운터
- **📅 새 하루 시작 (아카이브)**: 완료된 항목은 보관함으로 옮기고 미완료 항목만 남겨 새로운 루틴 시작
- **💾 데이터 백업 및 복원**: JSON 파일 Export / Import 지원

### 🛠️ 기술 스택
- **Frontend**: 순수 HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Storage**: 브라우저 `localStorage` (별도 서버 설치나 DB 없이 영구 데이터 저장)
- **Zero-Dependency**: 외부 무거운 프레임워크나 빌드 도구 없이 즉시 구동

### 🚀 실행 방법
별도의 웹 서버나 패키지 설치가 필요 없습니다.
1. `study_02` 폴더로 이동합니다.
2. [`index.html`](./study_02/index.html) 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하여 실행합니다.

## 3. [study_03] 정보처리기사 기출 퀴즈 게임 (CBT Quiz App)

국가기술자격 정보처리기사 필기 기출문제를 가볍고 재미있게 풀며 합격을 준비할 수 있는 반응형 웹 퀴즈 게임 애플리케이션입니다.

### ✨ 주요 기능
- **📚 5개 전 과목 600문항 기출문제 은행 & 실전 6대 게임 모드**:
  - 소프트웨어 설계, 소프트웨어 개발, 데이터베이스 구축, 프로그래밍 언어 활용, 정보시스템 구축관리 5개 과목(과목별 120문항 균형) 완벽 수록
  - **📋 실전 CBT 모의고사**: 5과목 균등 출제(10문항) 및 실제 시험 규정인 **과목별 40점 미만 과락 진단표** 실시간 제공
  - **⚡ 서바이벌 데스매치**: 단 한 번의 오답으로 즉시 탈락하는 극한의 집중력 훈련 (1-Life)
  - **⏱️ 10초 타임어택**: 문제당 10초 제한시간으로 순발력 및 핵심 키워드 직관 포착 훈련
  - **📚 과목별 집중 공략**: 취약한 특정 과목만 선택하여 10문제 집중 학습
  - **📝 스마트 오답노트**: 틀린 문제를 로컬스토리지에 자동 수집하고 오답만 모아 재시험 (맞히면 자동 졸업)
  - **🎯 클래식 10제**: 600문항 은행에서 10문제를 무작위 추출하여 가볍게 점검하는 표준 모드
- **💎 역동적인 복합 점수 & 콤보 시스템**:
  - 정답 기본 배점(100pt) + 연속 정답 콤보 보너스(+25~+100pt) + 스피드 판단력 보너스(3초/6초/10초)
  - 콤보 누적 시 Web Audio 효과음 피치 상승 및 화려한 불꽃 애니메이션 연출
  - 최종 점수 및 정답률 기반 5단계 티어 배지 수여 (👑 S등급 / 🥇 A등급 / 🥈 B등급 / ⚠️ C등급 / 🚨 F등급)
- **⚡ 즉각적인 피드백 & 💡 상세 해설 영역**: 보기 클릭 즉시 정오답 시각 피드백 및 상세 해설 제공
- **⏱️ 실시간 타이머 & 🏆 클린 랭킹 시스템(Leaderboard)**: LocalStorage 기반 순수 사용자 기록 랭킹 관리
- **🏅 가상 합격 판정**: 60점 이상 합격 메달 및 Canvas Confetti 폭죽 효과 연출
- **🌓 다크 / 라이트 모드 & ⌨️ 키보드 단축키**: 1~4번 키 선택, 스페이스/엔터 진행, ESC 팝업 닫기 지원
- **🛠️ Antigravity 커스텀 명령어 탑재**: `.antigravity/commands/`에 문제 추가(`/quiz-add`), 데이터 무결성 검증(`/quiz-validate`, `/test-quiz`), 통계 분석(`/quiz-range`) 지원

### 🛠️ 기술 스택
- **Frontend**: 순수 HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Audio & Visual**: Web Audio API (외부 오디오 파일 없는 실시간 주파수 신디사이저), HTML5 Canvas Confetti
- **Storage**: 브라우저 `localStorage` (무설치, 영구 데이터 보관)
- **Zero-Dependency**: 외부 라이브러리 및 CDN 의존성 0% 단독 실행

### 🚀 실행 방법
별도의 웹 서버나 패키지 설치가 필요 없습니다.
1. `study_03` 폴더로 이동합니다.
2. [`index.html`](./study_03/index.html) 파일을 웹 브라우저에서 더블 클릭하여 실행합니다.

## 4. [study_03_01] 리눅스마스터 2급 CBT & 합격 마스터 (Linux Master CBT & Study Hub)

국가공인 **리눅스마스터 2급(1차 및 2차 시험)** 합격을 위한 실전 CBT 퀴즈 및 핵심 요약 정리 통합 반응형 웹 애플리케이션입니다.  
공인 문제집의 **486개 기출 전 문항**과 **11개 챕터 핵심 이론**을 전수 추출하고, 리눅스 표준 man-pages 및 공인 시험 기준에 따라 **철저한 교차검증(Cross-Verification)**을 거쳐 완성되었습니다.

### ✨ 주요 기능
- **🐧 1차 & 2차 완전 분리 486문항 기출문제 은행**:
  - 상단 퀵 스위처로 `[전체]`, `[1차 대비 (88제)]`, `[2차 대비 (398제)]`를 클릭 한 번으로 전환
  - 1차 시험(역사, 라이선스, 배포판, 설치, 기본 명령어)과 2차 시험(운영/관리, vi, 패키지, 네트워크 등) 맞춤 분리
- **🛡️ AI 정답 전수 교차검증 (Cross-Verification) & 맞춤 해설**:
  - POSIX.1-2017, Linux Man-Pages, FHS 3.0, IANA 표준 네트워크 포트 규격 전수 대조 완료
  - 외부 블로그 URL 잔여물 100% 세척 및 명령어/터미널 프롬프트 띄어쓰기(공백) 전수 교정
  - 명령어의 속성(Attribute), 옵션 기능(-a, -l, -R 등), 프로토콜 동작 원리를 분석한 **1:1 맞춤형 전문 해설**
  - 복수 정답 문항(예: reboot 설명 오류 등) 식별 배지 및 다중 정답 채점 엔진 지원
- **🎮 합격 대비 7대 전문 퀴즈 & 학습 모드**:
  1. **💡 학습형 연습 모드 (Practice)**: 풀자마자 정답/해설이 펼쳐지며, 풀기 전 **[💡 정답 & 해설 바로보기]** 지원
  2. **📋 실전 CBT 모의고사 (Mock Exam)**: 1차 20문항 / 2차 40문항 출제, 60점 합격선 판정 및 과목별 과락 진단표 제공
  3. **⚡ 서바이벌 데스매치 (Survival)**: 1-Life 극한 훈련 (오답 즉시 탈락, 최고 연속 정답 기록 측정)
  4. **⏱️ 10초 타임어택 (Time Attack)**: 10초 제한시간으로 직관적 키워드 순발력 강화
  5. **🎯 과목/챕터별 집중 공략 (Mastery)**: 파일시스템, 쉘, 프로세스, 에디터 등 11개 챕터 선택 학습
  6. **🛡️ 교차검증 킬러문항 (Killer)**: umask 계산, SetUID/Sticky Bit, 시그널 번호, 서브넷팅 등 함정 문제 집중 출제
  7. **🔄 스마트 오답노트 (Wrong Note)**: 틀린 문제만 로컬 스토리지에 자동 수집하여 100% 정답까지 반복 재시험
- **📖 11개 챕터 핵심 요약 정리관 (Study Hub)**:
  - 1차 단기 합격 필수 암기장(역사, 라이선스 완벽 비교표, 런레벨 0~6)
  - 2차 10대 핵심 챕터 총정리(FHS 구조, umask 계산 공식, 특수 권한, vi 단축키, tar/rpm 옵션, 네트워크 포트 등)
  - 실시간 키워드 검색, 아코디언 펼침, 가독성 최적화
- **📱 [핵심] 스마트폰 완전 오프라인 지원 (Zero-Server Single File)**:
  - 모든 CSS, JS, 문제 486개, 요약집이 단 하나의 파일에 통합된 [`linux_master_offline.html`](./study_03_01/linux_master_offline.html) 제공
  - 카카오톡/에어드랍으로 스마트폰에 전송하여 Wi-Fi나 데이터 연결 없이 지하철/비행기에서 100% 오프라인 구동
  - GitHub Pages 정적 호스팅 무료 배포 가이드 및 PC 내 모바일 뷰 에뮬레이터 지원
- **⌨️ 키보드 단축키 & Web Audio 사운드**: 1~4번 보기 선택, 스페이스/엔터 진행, ESC 닫기, 음향 효과

### 🛠️ 기술 스택
- **Frontend**: 순수 HTML5, CSS3 (모바일 퍼스트 반응형 레이아웃), Vanilla JavaScript (ES6+)
- **Audio Engine**: Web Audio API (외부 파일 의존 없는 프로시저럴 주파수 합성)
- **Storage**: 브라우저 `localStorage` (무설치, 영구 보관)
- **Zero-Dependency**: 외부 CDN 및 라이브러리 의존성 0% 단독 실행

### 🚀 실행 방법
- **PC 브라우저**: `study_03_01` 폴더의 [`index.html`](./study_03_01/index.html)을 더블 클릭하여 실행합니다.
- **모바일 오프라인**: `study_03_01` 폴더의 [`linux_master_offline.html`](./study_03_01/linux_master_offline.html)을 스마트폰으로 전송 후 브라우저로 엽니다.
