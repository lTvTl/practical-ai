# [PRD Step 3] 사용자 프로필 및 나만의 레시피북 저장·관리 시스템 (`prd_step3.md`)

## 1. 단계 개요 (Overview)
- **단계명**: Step 3 — 사용자 맞춤형 프로필 관리 및 레시피 아카이빙(레시피북)
- **목적**: 사용자별 프로필(식이 제한, 알레르기, 요리 숙련도, 선호 테마)을 생성·관리하고, Step 2에서 생성된 AI 레시피와 완성 요리 이미지를 프로필별로 영구 저장·분류·검색·재열람할 수 있는 개인화 레시피 관리 환경을 구축한다.
- **핵심 가치**:
  - 다중 프로필 또는 개인 맞춤 프로필 설정을 통해 알레르기/기피 식재료를 레시피 생성 단계에서 사전 필터링
  - 생성된 레시피와 이미지, 나만의 조리 후기/메모, 별점을 한곳에서 관리하는 디지털 레시피북
  - 데이터 유실 방지를 위한 로컬/파일 영속화 및 JSON 백업(Export)·복원(Import) 지원

## 2. 기능 요구사항 명세 (Functional Requirements)

### 2.1 사용자 프로필 생성 및 맞춤 설정
| 기능 ID | 기능명 | 상세 내용 |
| :--- | :--- | :--- |
| **FR-301** | **프로필 생성 및 전환** | 사용자 이름(닉네임), 프로필 아이콘/아바타, 한 줄 소개를 설정하여 프로필 생성 및 다중 프로필 간 전환 지원 |
| **FR-302** | **알레르기 및 기피 식재료 등록** | 갑각류, 견과류, 유제품, 고수, 오이 등 알레르기/기피 식재료를 등록하면 Step 2 레시피 생성 시 자동 제외 조건으로 반영 |
| **FR-303** | **식단 성향 및 숙련도 설정** | 식단 유형(일반식, 고단백/식단관리, 채식 등) 및 요리 숙련도(초보/중급/고수) 기본값 저장 |
| **FR-304** | **프로필 대시보드 통계** | 총 저장한 레시피 수, 직접 요리 완료(`Cooked`) 횟수, 선호 요리 카테고리 비중, 자주 사용한 식재료 Top 5 시각화 |

| 기능 ID | 기능명 | 상세 내용 |
| :--- | :--- | :--- |
| **FR-305** | **레시피 원클릭 저장** | Step 2에서 생성된 레시피(요리명, 재료, 조리 단계, `recraft` 생성 이미지)를 현재 활성 프로필의 레시피북에 저장 |
| **FR-306** | **저장된 레시피 목록/갤러리 뷰** | 카드 그리드(완성 요리 이미지 중심) 및 리스트 뷰 전환, 상세 모달 열람 지원 |
| **FR-307** | **즐겨찾기(⭐) 및 요리 완료 체크** | 자주 해 먹는 레시피를 즐겨찾기(`starred`)로 고정하고, 실제 요리한 횟수(`cookedCount`)와 마지막 조리일 기록 |

| :--- | :--- | :--- |

## 4. 완료 기준 (Acceptance Criteria)
1. 사용자가 프로필(닉네임, 알레르기/기피 재료, 선호 식단)을 생성·수정할 수 있어야 하며, 해당 설정이 Step 2 레시피 생성 조건에 연동되어야 한다.
2. Step 2에서 생성된 레시피와 요리 이미지를 프로필의 레시피북에 저장하고, 별점·메모 수정, 즐겨찾기 토글, 삭제가 정상 동작해야 한다.
3. 페이지 새로고침 후에도 프로필과 저장된 레시피 목록(이미지 포함)이 그대로 유지되어야 하며, JSON 백업 및 복원이 정상 작동해야 한다.
