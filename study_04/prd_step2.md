# [PRD Step 2] 인식된 식재료 기반 AI 레시피 추천 및 요리 이미지 생성 (`prd_step2.md`)

## 1. 단계 개요 (Overview)
- **단계명**: Step 2 — 식재료 기반 맞춤형 레시피 생성 및 시각화
- **목적**: Step 1에서 확정된 식재료 목록과 사용자의 조리 조건(요리 카테고리, 조리 시간, 난이도, 인분 수)을 바탕으로 맞춤형 레시피를 생성하고, `recraft/recraft-v4.1-flash-v2:free` 모델을 활용해 완성 요리의 고품질 비주얼 이미지를 함께 생성하여 제공한다.
- **사용 AI 모델**:
  - `recraft/recraft-v4.1-flash-v2:free` : 레시피 정보 기반 완성 요리 이미지 생성 (`text -> image`, WebP Data URL 반환)
  - `inclusionai/ling-3.2-flash:free` (보조 텍스트 생성 파이프라인) : 식재료 조합 기반 상세 레시피 텍스트(조리 순서, 계량, 팁) 구조화 생성 (`text -> text`)
  > **기술 참고**: OpenRouter에서 `recraft/recraft-v4.1-flash-v2:free`는 프롬프트를 입력받아 `choices[0].message.images` 배열에 완성 이미지를 반환하는 Text-to-Image 특화 모델이므로, 레시피 상세 텍스트 생성과 완성 요리 이미지 생성을 유기적으로 결합하여 풍부한 레시피 카드를 구성한다.

## 3. 기술 사양 및 데이터 스키마 (Technical Specifications)

### 3.1 API 엔드포인트 설계
- `POST /api/step2/generate-recipe`
  - **Input**: Step 1에서 확정된 `ingredients` 배열 + 사용자 옵션(`cuisine`, `maxTime`, `difficulty`, `servings`)
  - **Process**:
    1. 식재료 목록을 기반으로 구조화된 JSON 레시피 데이터 생성
    2. 생성된 레시피의 영문 비주얼 프롬프트(`imagePrompt`)를 `recraft/recraft-v4.1-flash-v2:free`에 전달하여 완성 요리 이미지(Base64 WebP) 획득 및 경량화
  - **Output**: 레시피 상세 JSON + 생성된 이미지 URL/Data URL

## 4. 완료 기준 (Acceptance Criteria)
1. Step 1에서 전달된 식재료가 실제 레시피의 주재료(`ingredients.owned`)로 정확히 반영되어야 한다.
2. `recraft/recraft-v4.1-flash-v2:free` 모델을 통해 생성된 완성 요리 이미지가 레시피 카드 상단에 정상 렌더링되어야 한다.
3. 생성된 레시피를 Step 3의 사용자 프로필에 즉시 저장할 수 있는 액션 버튼이 동작해야 한다.
